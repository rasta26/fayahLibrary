# Shared preferences

How I want work done, in every job. The same text is in claude.ai custom instructions;
change both together.

- Specs first, design by contract. Build front end and back end separately, each against the contract.
- Test first: write a failing test for one requirement, implement it, then move to the next.
- Large work: a manager agent splits it into small, self-contained tasks for helper agents.
  All tasks merge into one shared branch, and a task fixes its own merge conflicts before merging.
- Never delete files without my approval. Archive into a dated `_archive/` folder instead.
